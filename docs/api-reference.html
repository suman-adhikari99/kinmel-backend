API Reference

Quick reference for all Kinmel API endpoints

Base URL: http://localhost:8000/api/v1
🔐 Authentication Required: Include JWT token in header: Authorization: Bearer <token>

🏥 Health Checks

GET /health Basic health check
Response
{
  "status": "healthy",
  "service": "kinmel"
}

📦 Inventory Operations

POST /inventory/receive Receive stock from supplier Staff+
Request Body
{
  "sku": "MILK-2L-WHOLE",
  "location_id": "uuid",
  "quantity": 50,
  "batch_number": "BATCH-001",
  "expiry_date": "2024-02-15T00:00:00Z",
  "notes": "Weekly delivery"
}
cURL Example
curl -X POST localhost:8000/api/v1/inventory/receive \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sku":"MILK-2L","location_id":"...","quantity":50}'
POST /inventory/adjust Manual stock adjustment Manager+
Request Body
{
  "sku": "MILK-2L-WHOLE",
  "location_id": "uuid",
  "new_quantity": 45,
  "reason": "cycle_count",
  "notes": "Cycle count found 5 missing",
  "confirm_large_adjustment": false
}
Valid Reasons
ReasonDescription
cycle_countPhysical count correction
audit_correctionAuditor adjustment
shrinkageUnexplained loss
POST /inventory/reserve Reserve stock for order Staff+
Request Body
{
  "sku": "MILK-2L-WHOLE",
  "location_id": "uuid",
  "quantity": 5,
  "order_id": "ONLINE-001"
}
POST /inventory/fulfill Fulfill order (sell stock) Staff+
Request Body
{
  "sku": "MILK-2L-WHOLE",
  "location_id": "uuid",
  "quantity": 5,
  "order_id": "ORD-001"
}
GET /inventory/stock/{sku} Get stock level Staff+
Query Parameters
ParamTypeDescription
location_iduuidFilter by location (optional)
Response
{
  "sku": "MILK-2L-WHOLE",
  "physical_stock": 50,
  "buffer": 5,
  "online_available": 45,
  "reorder_point": 10,
  "is_low_stock": false
}

🔐 Admin & Audit

GET /admin/audit-log Query audit trail Manager+
Query Parameters
ParamTypeDescription
skustringFilter by product SKU
action_typeenumreceiving, sale, adjustment, disposal
start_datedatetimePeriod start (ISO 8601)
end_datedatetimePeriod end
performed_bystringUser name (partial match)
limitintMax records (1-500)
offsetintSkip records
Response
{
  "entries": [
    {
      "sku": "MILK-2L-WHOLE",
      "action_type": "sale",
      "quantity_delta": -2,
      "quantity_before": 50,
      "quantity_after": 48,
      "performed_by": "John Smith",
      "timestamp": "2024-01-15T14:30:00Z"
    }
  ],
  "total": 150,
  "has_more": true
}
GET /admin/audit-log/export.csv Export as CSV Manager+
cURL Example
curl "localhost:8000/api/v1/admin/audit-log/export.csv?start_date=2024-01-01" \
  -H "Authorization: Bearer $TOKEN" \
  -o audit_export.csv
GET /admin/audit-log/stats Aggregated statistics Manager+
Response
